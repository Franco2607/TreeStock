# Tree-Stock

## Objetivo

El objetivo de esta actividad es comprender el funcionamiento de los árboles binarios de búsqueda mediante el desarrollo de una aplicación en Java para gestionar un inventario de productos.

---

## Descripción

Tree-Stock es una aplicación de consola que permite registrar productos, mostrarlos de forma ordenada y buscarlos por su ID utilizando un árbol binario de búsqueda.

---

## Funcionalidades

* Registrar productos (ID y nombre).
* Mostrar inventario ordenado.
* Buscar productos por ID.
* Salir del programa.

---

## Instrucciones de Ejecución

1. Abrir el proyecto en Visual Studio Code.
2. Ejecutar la clase Main.java.
3. Utilizar el menú para registrar, consultar y buscar productos.
